# m82-galactic-outflow
Multi-band photometric reduction of HST FITS data to analyze surface brightness profiles and ionized gas outflow morphology in starburst galaxy Messier 82.
## Data & Reproducibility Note
- **Raw Observations:** Archival HST FITS files are excluded from this repository via `.gitignore` due to large file sizes.
- **Access:** Raw data can be retrieved directly from the Mikulski Archive for Space Telescopes (MAST) using the dataset IDs referenced in `data/metadata.txt`.
- **Processed Outputs:** Calibrated intensity tables, region definitions (`.reg`), and spatial flux profiles are included directly in the `data/` and `figures/` directories for full reproducibility.
