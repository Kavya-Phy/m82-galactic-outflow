# m82-galactic-outflow
Multi-band photometric reduction of HST FITS data to analyze surface brightness profiles and ionized gas outflow morphology in starburst galaxy Messier 82.
## Dataset & Reproducibility
- **Source:** Archival multi-wavelength imaging from the Hubble Space Telescope (HST).
- **Target:** Messier 82 (NGC 3034) starburst core and minor-axis outflow regions.
- **Analysis:** Photometric reduction, background subtraction, and aperture flux measurements were performed using SAOImage DS9 and Python (`Astropy`, `NumPy`, `Matplotlib`).
- **Data Products:** Spatial intensity distributions, region definitions, and calibrated flux profile plots generated from the HST data are hosted in this repository.
